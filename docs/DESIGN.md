# DESIGN v2 — ae-portfolio ("listening plate")

Concept: หน้าเปิดตัวฮาร์ดแวร์ระดับไฮเอนด์ของ "แผ่นที่ฟังเสียงรอยร้าว" ภาพหลักคือต้นแบบจริงในรูป 3 มิติ (แผ่นอะคริลิก + เพียโซทองเหลือง 4 ตัว) ทุกภาพประกอบในหน้าใช้ภาษาเดียวกัน: แผ่น 30×30, เซนเซอร์สีทองเหลือง, คลื่นสีฟ้าเขียว
v1 (T2) แบนและเป็นตัวหนังสือล้วน → v2 เพิ่มความลึก จังหวะ layout ที่ต่างกันทุก chapter รูปจริงเป็นช่วงภาพใหญ่ และลูกเล่นที่ "อธิบาย" ไม่ใช่แค่ประดับ

- brass (สีแผ่นเพียโซ) `#d6b06a` — เซนเซอร์, หมายเลข, ป้ายรอง (ใช้น้อย)
- ระดับพลังงาน: `#3dda84` / `#f2c744` / `#ff5d5d` (ใช้กับการจำแนก 3 ระดับ + สถานะ + ป้าย "จำลอง" สีเหลือง)

## Type
- Latin display + ตัวเลขใหญ่: **Geist** 200–600 (tabular nums) — ตัวเลขสำคัญ weight 200 ขนาดใหญ่
- ไทย: **IBM Plex Sans Thai** 300/400/500/600 — body 300, line-height 1.8 (ไม่มี letter-spacing กับภาษาไทย)
- ข้อมูล/readout: **Geist Mono** 400/500 (fallback Plex Sans Thai สำหรับอักษรไทยใน canvas)
- สเกล: 13 / 15 / 17 / clamp 1.15–1.4rem / clamp 1.4–2rem / h2 clamp 2.2–4.6rem / mega clamp 2.6–7rem ; H1 EN clamp 2.3–4.4rem 4 บรรทัด (บรรทัด 3 จาง, บรรทัด 4 ไล่สีเป็น signal)

## Components
- **นโยบาย T8: หนึ่ง chapter หนึ่ง interaction (ไม่ซ้ำกัน)** — กล่อง/พื้นผิวกลับมาใช้ได้ (glass, radius 18-26px, ขอบ hairline ใน) แต่ห้ามเป็นกริดกล่องหน้าตาเหมือนกันที่นิ่งเฉย (ลูกค้าว่าดูเหมือน AI ทำ) และห้ามใช้เส้น hairline/ตารางเป็นภาษาหลัก (T7 ถูกปฏิเสธ). ทุก chapter ต้องมีรูปแบบการโต้ตอบของตัวเองที่เกี่ยวกับเนื้อหา (AE/TDOA/เซนเซอร์/รอยร้าว) และห้ามซ้ำกันข้าม chapter. ถ้าเพิ่ม section ใหม่ ต้องคิด pattern ใหม่ที่ไม่ตรงกับตารางด้านล่าง
- **กติกาของทุก interaction**: เนื้อหาไทยครบและอ่านได้แม้ไม่มี JS (JS แค่เพิ่มการสลับ/ลำดับ, ตัวควบคุมซ่อนไว้จนกว่าจะมี `.is-on`); tabs ใช้ `role=tablist/tab/tabpanel` + ลูกศร/Home/End; ทุก hover มีเทียบเท่า tap/focus; `prefers-reduced-motion` = แสดงสถานะสุดท้ายนิ่ง; ไม่มี horizontal scroll ที่ 375px; vanilla JS (`assets/js/interact.js`) + CSS เท่านั้น
- **Cursor glow + tilt การ์ด** ใช้ได้เฉพาะ 10 ผู้จัดทำ (`.tc[data-tilt]`)
- `.instrument` — แผงเครื่องมือ (demo, scope, calibration, energy) มีเงาและเรืองแสงฟ้าเขียวจางๆ
- `.chap` — เลข chapter ใหญ่แบบ outline + ป้ายอังกฤษ + h2 ไทย (h2 แตกเป็นคำด้วย Intl.Segmenter แล้วเผยทีละคำ ไม่ตัดกลางพยางค์ไทย)
- `.band` — ภาพเต็มจอ ปรับโทน (saturate/contrast ต่ำ + vignette + tint ฟ้าเขียว/ทองเหลือง) มี parallax หรือ clip-path reveal
- `.badge` สีเหลือง = "จำลอง" ทุกจุดที่เป็นภาพ/ข้อมูลจำลอง (hero HUD, demo, scope, energy slider)

## Motion
- Lenis smooth scroll + GSAP ScrollTrigger (scrub parallax, clip reveal, timeline fill, progress, gallery pin) ; reveal/เลขวิ่ง/ลำดับเหตุการณ์ใช้ IntersectionObserver + CSS transition (ทำงานได้แม้ CDN ล่ม)
- Micro: custom cursor (dot + ring, เปลี่ยนเป็นกรอบสี่เหลี่ยมทองเหลืองบนเดโม่), ปุ่ม magnetic, tilt แกลเลอรี, scramble ตัวเลข
- 3D hero: ~60fps หยุดเมื่อออกนอกจอ/แท็บซ่อน, มือถือ DPR ≤1.5 + mesh น้อยลง
- **prefers-reduced-motion**: ไม่มี boot, ไม่มี Lenis/pin/scrub/marquee, ทุก animation แสดงสถานะสุดท้าย, 3D render เฟรมเดียว, canvas อธิบายแสดงภาพนิ่งของแต่ละขั้น

## T9 additions
- **หัวข้อ chapter (ใช้ร่วมทุกบท)**: บรรทัดเดียว `01 / 10  EYEBROW ────` (mono) โดยเส้นด้านขวาเติมสี signal ตามสัดส่วน chapter/10 (`--ch` ตั้งด้วย JS) แล้วตามด้วย h2 ใหญ่ 1 บรรทัด และ intro ใต้หัวข้อ (ไม่แยกสองคอลัมน์ ไม่มีเลขโครงตัวใหญ่)
- **Selector H1-H4**: ปุ่มมีกรอบ/พื้นแม้ยังไม่เลือก, hover ยกขึ้น, ตัวที่เลือกมี chevron ชี้ไปที่แผง, มีข้อความ hint, ปุ่มก่อนหน้า/ถัดไป + ตัวนับ + แถบความคืบหน้า, เลื่อนอัตโนมัติช้า (6.5 วิ) จนกว่าผู้ใช้แตะ; แผงแบ่ง claim | gauge ในกรอบ
- **อุปกรณ์ = kit panel**: รูปซ้าย (สลับตามแท็บ) + segmented control + ตัวเลขจำนวนรายการ + รายการแถวเดียวสเปกชิดขวาแบบ mono (ไม่มีกริดกล่อง)
- **Accuracy**: plot ใหญ่ซ้าย, แถวข้อมูล 3 ชุดขวา; hover/focus/แตะแถว หรือแตะจุดบน plot จะไฮไลต์คู่กันทั้งสองทาง
- **Deck shuffle (02 = fan ข้างๆ, 04 = flip ขึ้น)**: การ์ดที่ pin มีการ์ดโผล่ 2 ใบด้านหลัง; ตอนเปลี่ยนขั้น snapshot การ์ดเก่า (`deck.js`) บินออก/หมุนแล้วซุกหลังกอง ส่วนการ์ดจริงที่เป็นขั้นใหม่เลื่อนมาอยู่หน้า (transform/opacity, WAAPI ~0.3+0.4 วิ, ย้อนทิศเมื่อเลื่อนกลับ); reduced motion = crossfade. การ์ดถูกจัดกลางจอ (`--card-h`) และข้อความขั้นจัดกึ่งกลางเทียบการ์ด
